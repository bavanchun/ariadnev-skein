- App version in frame: **1.2.2** or newer, so the accent colour reads as rope

- 2560×1600 (Retina), lossless PNG or JPEG-90, minimum 1920×1200.
- No visible username, email, notification, badge, or unrelated menu bar app.
- Light mode is the baseline; `-dark` suffix for optional dark duplicates.
